# تطبيق معلم الرياضيات الذكي (المناهج السعودية) 🇸🇦

تطبيق أندرويد متكامل ومصمم خصيصاً لطلاب المناهج السعودية (من الصف الأول الابتدائي حتى الصف الثالث ثانوي مسارات وعام)، يجمع بين دقة الحل الرياضي الخالي من الحشو، وشرح المعلم الصوتي الودود باللهجة السورية الشامية.

---

## ✨ ميزات التطبيق

1. **التقاط أو كتابة المسألة**:
   * تصوير مباشر للمسألة من الكتاب أو الدفتر عبر الكاميرا.
   * إمكانية اختيار صورة سابقة من معرض الصور.
   * إدخال المعادلة أو المسألة نصياً.

2. **الفحص الدقيق للمنهج السعودي**:
   * يتحقق التطبيق تلقائياً مما إذا كانت المسألة تقع ضمن المناهج المقررة لوزارة التعليم في المملكة العربية السعودية (ابتدائي - متوسط - ثانوي).
   * في حال كانت المسألة جامعية أو خارج المنهج المقبول، يقدم التطبيق اعتذاراً واضحاً ومحترماً يوضح أن المسألة خارج المقرر.

3. **خطوات الحل الصافية للدفتر (Notebook Steps)**:
   * تم ضبط النموذج بدقة ليعطي خطوات رياضية نقية ومرتبة خطوة بخطوة بدون أي كلام إنشائي أو شروحات كلامية مطولة.
   * الناتج مصمم ليكون جاهزاً فوراً لنقله إلى الكتاب أو الدفتر بضغطة زر "نسخ للدفتر".

4. **شرح صوتي متزامن باللهجة الشامية (EdgeTTS)**:
   * يعتمد على تقنية **Microsoft Edge TTS** المفتوحة والمجانية بالكامل وبدون الحاجة لأي مفتاح إضافي.
   * يستخدم الأصوات الشامية الرسمية (`ar-SY-LaithNeural` للأستاذ ليث، و `ar-SY-AmanyNeural` للمعلمة أماني).
   * أسلوب الشرح لطيف ومحفز للطلاب كأنه معلم خاص يشرح بجانبه.

---

## 🛠️ البنية التقنية (Architecture)

* **لغة البرمجة**: Kotlin
* **واجهات المستخدم**: Jetpack Compose (Material 3) مع دعم كامل للغة العربية (RTL).
* **إدارة الحالات**: MVVM Architecture + Kotlin Coroutines & StateFlow.
* **الذكاء الاصطناعي**: Google Gemini 1.5 Flash (عبر REST API سريع ومباشر).
* **توليد الصوت الشامي**: Microsoft Edge ReadAloud WebSocket API (EdgeTTS).
* **تشغيل الصوت**: Android MediaPlayer مع مؤشرات تفاعلية وتنبيهات نابضة.

## 📱 كيفية تشغيل التطبيق وتوليد ملف APK

### الطريقة الأولى: عبر Android Studio (الأسهل والأسرع محلياً)
1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد المجلد:
   `C:\Users\okyi\.gemini\antigravity\scratch\smart_math_teacher_saudi`
3. انتظر انتهاء مزامنة الـ Gradle.
4. من القائمة العلوية اضغط على:
   **Build > Build Bundle(s) / APK(s) > Build APK(s)**
5. سيظهر لك إشعار في الزاوية بمكان ملف الـ APK الجاهز (`app-debug.apk`) لتنقله إلى هاتفك وتثبته مباشرة!

---

### الطريقة الثانية: التوليد التلقائي عبر GitHub Actions (سحابياً بدون تثبيت برامج)
1. قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub.
2. ارفع مجلد المشروع كاملاً إلى المستودع.
3. ملف العمل (`.github/workflows/build_apk.yml`) سيبدأ البناء تلقائياً على خوادم GitHub.
4. بعد دقائق قليلة، ستجد ملف الـ APK جاهزاً للتحميل في تبويب **Actions > Artifacts**.
